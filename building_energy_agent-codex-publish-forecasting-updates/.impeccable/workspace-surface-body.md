## Scope and mode

The complete `apps/web` workspace in **Operate** mode.

## Audience, job and constraints

Building-energy engineers upload immutable source snapshots, request deterministic
analysis, monitor long Codex/Skill work, answer genuine ambiguities and inspect
traceable results. Chat remains primary. Activity is rich but sanitized. Every
status and metric comes from server contracts. Desktop uses three columns;
tablet and mobile use single-instance accessible drawers.

## Chosen direction

Modern building-commissioning strip chart: exact ruled structure, restrained
instrument colors and a thin truthful load trajectory carrying plan order,
parallel branches and current state. Approved comp:
`.impeccable/mocks/workspace-a.png`.

## Component grammar and inventory

| Ingredient | Commitment | Medium |
| --- | --- | --- |
| App shell | 224px rail, flexible conversation, 340px inspector | semantic HTML/CSS grid |
| Load trajectory | thin plotted line, real nodes, optional branch, one active pulse | responsive SVG |
| Navigation | compact rows, hairline selection field, no icon-only mystery controls | HTML buttons/links |
| Conversation | turn-grouped messages with restrained surfaces and ruled headers | React/HTML |
| Question group | fieldset semantics, saved drafts, one submit action | React forms |
| Result summary | horizontal instrument readout; details collapsed | React/HTML |
| Activity | todo, Skill progress, sanitized command/output, usage and errors | React/HTML/SVG |
| Drawers | one content instance moved by CSS/layout, focus trap and return focus | React dialog |
| Type | Chinese workhorse sans; condensed stage utility; mono time/hash | local/system CSS stacks |

## Must not be literalized

Generated comp metrics, file names, model names and commands are synthetic design
material. The build must render only contract data, never unsupported artifacts,
fake values or hidden reasoning.
