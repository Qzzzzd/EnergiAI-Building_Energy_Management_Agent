# dq-v1 公式

六个维度的权重分别为：DQ1 0.20、DQ2 0.20、DQ3 0.05、DQ4 0.05、DQ5 0.20、
DQ6 0.30。

- DQ1：对加权缺失率应用已定义的分段评分；缺失率同时包括空值和应有但不存在的时间戳。
- DQ2：对各异常规则标记并集得到的异常率应用同一分段评分。
- DQ3：计算各预期语义特征组覆盖率的平均值。
- DQ4：使用 `theta4` 合并有效值域跨度覆盖率和有效时间跨度覆盖率。
- DQ5：使用 `theta5` 合并加权绝对 Spearman 相关性和时间一致性。
- DQ6：计算 `(H / log2(m))² × 100` 的加权平均值。

数据缺失属于质量问题，应按规则扣分或计 0。只有在目标映射、足够的有效配对样本等计算前提
不成立时，维度才标记为 `unavailable`。只要存在不可计算维度，就不生成综合分。
